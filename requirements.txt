# nanocosmos -- pinned runtime dependencies (lockfile).
#
# Role of this file
# -----------------
# This is the *frozen* version of every package needed to reproduce the
# CUDA-13 / Python-3.12 development environment.  It bundles together
# the core runtime, the Cosmos backbone, the GPU (RAPIDS) extras, the
# download-script helpers, the optional visualizer, AND the dev/test
# tooling -- in other words, every ``[project.optional-dependencies]``
# group from ``pyproject.toml`` rolled into one installable manifest.
#
# When to use which file
# ----------------------
#   * ``pip install -r requirements.txt``      -- bit-for-bit reproduction
#                                                of the dev environment.
#   * ``pip install -e ".[cosmos,dev]"``       -- permissive lower bounds,
#                                                pulled from pyproject.toml.
#   * ``pip install -e ".[cosmos,fp8,gpu-cu13,viz,scripts,figures,dev]"``
#                                              -- equivalent of this lockfile
#                                                without the exact pins.
#
# Keep ``pyproject.toml`` as the single source of truth for the package's
# logical dependency *groups*; this file just freezes specific resolved
# versions on top of that.

# Cosmos backbones (Cosmos 2.5 Predict + Cosmos 3 Nano)
#
# The default backbone (``model.type: cosmos3nano3d``) loads
# ``Cosmos3OmniTransformer``, which is NOT in any tagged diffusers
# release yet -- the pinned 0.37.0 only ships the Cosmos 2.5 classes
# (``CosmosTransformer3DModel`` etc.).  Without the git-main build the
# wrapper falls back to a randomly-initialised DiT (logged as a warning
# in ``_BaseCosmos25Wrapper``; see wrapper_base.py).  git main still
# ships every Cosmos 2.5 class, so Predict keeps working.
#
# [verify-weights] Pinned to the exact resolved commit
# (diffusers 0.39.0.dev0) so the lockfile is reproducible instead of
# tracking a moving branch.  Changing the diffusers / transformers /
# safetensors versions can change how HF weights deserialize into the
# DiT via ``from_pretrained``; re-verify pretrained-weight loading
# after any bump.  Re-pin to a tagged release once one exposes
# ``Cosmos3OmniTransformer``.
diffusers @ git+https://github.com/huggingface/diffusers.git@6d71b76aceff935192e58fee38c5cc5d8d227cf0
